# Volatile — downloads

*Humanity is gone. Production isn't.*

A co-op factory builder set in a toxic wasteland, by [Vortal](https://vortal.space/volatile).
Windows, Mac and Android all play together in co-op.

**[Download for Windows](https://github.com/UniversalWebX/vortalsiterepo/raw/refs/heads/volatile-download/Volatile-win64.zip)** — unzip anywhere and run `Volatile.exe` (Windows 10/11, 64-bit).

**[Download for Mac](https://github.com/UniversalWebX/vortalsiterepo/raw/refs/heads/volatile-download/Volatile-macOS.zip)** — unzip, drag Volatile to Applications, then right-click it and choose **Open** the first time. *Volatile isn't on the Mac App Store yet, so macOS flags it as an "unidentified developer" app; if it's still blocked, go to System Settings → Privacy & Security → Open Anyway. The first launch takes a minute or two while macOS prepares the shaders.*

**[Download for Android](https://github.com/UniversalWebX/vortalsiterepo/raw/refs/heads/volatile-download/Volatile-android.apk)** — open the file on your phone and allow installing from your browser or files app (Android 8+, 64-bit).

**[Dedicated server for Linux](https://github.com/UniversalWebX/vortalsiterepo/raw/refs/heads/volatile-download/Volatile-linux-server.zip)** — a world that stays online on a Linux VPS: unzip, run `python3 server.py`, open UDP 7777. (On Windows, the game folder has `Start server.bat`.)

Every version updates itself from the main menu after that. Current version: **v1.0.0-beta.7**. Fixed: clicking a building or belt in dismantle mode (F) didn't remove it. Skipping the night in co-op: everyone presses K (SLEEP on phones), a banner shows who's ready, and pressing K again takes your vote back.

This branch only holds the latest downloads; the website lives on `main`.
